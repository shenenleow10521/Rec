01char c = Serial.read();02switch (c) {03  case 'F': drive(1, 1);   break;04  case 'B': drive(-1, -1); break;05  case 'L': drive(-1, 1);  break;06  case 'R': drive(1, -1);  break;07  case 'S': stopMotors();  break;08}
02Fail-safe / command timeout
09if (millis() - lastCmd >= FAILSAFE_MS) {10  stopMotors(); // no command for 5s → stop11}
The timeout guard is the safety feature: no new command for the configured interval → stop the drive motors. For this to work, lastCmd must be refreshed when a valid command arrives.

From a touch to robot motion.
The Android app maps a control, queues its command bytes and writes them to a Bluetooth serial socket. HC-05 bridges that stream to the Nano’s UART.

   

   
120 ms / held action
Drive and both claws have separate held-action groups. Each active group is repeated by the controller ticker.
SPP / RFCOMM
Connects to a paired HC-05/HC-06 using the serial-port service UUID:
00001101-0000-1000-8000-00805F9B34FB
9600 / companion UART
The provided companion sketch defaults to 9600 baud on D0/D1. This must match the Bluetooth module; the phone app does not configure UART baud.

  

  

   
Small commands. Separate responsibilities.
Raw firmware commands are listed below. The app’s direction settings can change which byte a labelled button sends.

   
FUNCTIONRAW COMMANDRELEASE / RESULT
DriveF B L RS stops the wheels
Left claw / ARMW XJ freezes its target
Right claw / GRIPE CK freezes its target
Motor PWM+ -±20 · range 80–255
Stop all motion!Wheels stop; servos hold
Status requestPRequests firmware status
EXAMPLE RECEIVED STATUS / COMPANION FORMATREC1 PWM=200 ARM=90 GRIP=90 DRIVE=STOPPED
PWM feedback describes the controller output, not measured road speed. The app also recognises the legacy “Speed: … Drive: …” format.
Pause is a priority action
The app clears queued motion and sends S, ! and P as separate CR/LF-delimited commands. It latches controls until Resume and retries the stop frame about every 240 ms.
600 ms actuator lease
The companion sketch stops an actuator if its motion command expires. This depends on the installed firmware; it is not guaranteed by a Bluetooth connection alone.
Transport ≠ confirmation
Connecting in raw serial mode does not require a REC1 handshake. A completed socket write is not a robot acknowledgement; the app uses received status to confirm PWM and stopped state.
Motion stop ≠ power cut
Pause stops motion in software. The robot’s physical switch is what disconnects power.
